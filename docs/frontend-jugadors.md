# Jugadors — publicació segura

El frontend públic no té accés directe al repositori privat ni conté credencials. Per defecte no hi ha jugadors ficticis. La previsualització es pot obrir explícitament amb `jugadors.html?demo=1`. El carregador permet seleccionar localment una còpia autoritzada del mestre, sense conservar el catàleg a l'emmagatzematge persistent. Els favorits i les fotos són preferències locals. El JSON real es transforma del contracte zonaok-jugadors-v1: players, memberships, matchAppearances; els marcadors es vinculen amb l'agenda pública per lliga i partit, no per coincidència aproximada. Les dades absents no són zeros; els GC de porter són d'equip. Falta desplegar un servei d'autenticació i una API autoritzada per a càrrega automàtica; no exposar el master ni tokens a Pages.
