Importar dades FECAPA

1. Obre FECAPA Agenda (/ag/) en Safari. Selecciona TOTS els clubs i el període complet de temporada (01/07/2026–30/06/2027). Espera que es vegi la taula completa.

2. Prem Compartir → «ZonaOK Agenda»; importa tots els partits de temporada del Barça i CP Sant Celoni que es vegin a la taula.

3. Per actualitzar marcadors, obre FECAPA → En directe i prem Compartir → «ZonaOK Resultats». Només s'aplicaran marcadors als partits que ja hagis importat d'Agenda i es puguin identificar amb seguretat.

4. Les dreceres reben «Pàgines web de Safari», executen JavaScript sobre la pàgina i obren l'URL retornada. No cal API ni servidor.

5. Per compartir les dades entre aparells, descarrega zonaok-data.json i publica'l a GitHub.

Les temporades s’importen des dels calendaris oficials de FECAPA. Els botons Magí i Ton conserven els partits importats per a tota la temporada. Les classificacions mantenen les tres dreceres existents.
