Importar dades FECAPA

1. Obre FECAPA Agenda (/ag/) en Safari. Selecciona TOTS els clubs i un període que inclogui el dilluns i diumenge d'aquesta setmana. Espera que es vegi la taula completa.

2. Prem Compartir → «ZonaOK Agenda»; importa només partits dels dos clubs. S'importen totes les files dels dos clubs que es vegin a la taula de la setmana.

3. Per actualitzar marcadors, obre FECAPA → En directe i prem Compartir → «ZonaOK Resultats». Només s'aplicaran marcadors als partits que ja hagis importat d'Agenda i es puguin identificar amb seguretat.

4. Les dreceres reben «Pàgines web de Safari», executen JavaScript sobre la pàgina i obren l'URL retornada. No cal API ni servidor.

5. Per compartir les dades entre aparells, descarrega zonaok-data.json i publica'l a GitHub.

Els resultats antics d'Agenda poden arribar més tard que En directe. Les classificacions es continuen important amb les tres dreceres anteriors.
