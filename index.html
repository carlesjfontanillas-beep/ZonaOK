CONSULTES RÀPIDES
Importar dades de FECAPA

1. Obre una competició de FECAPA amb Safari i espera que es mostrin els partits.

2. Prem Compartir → Prova FECAPA (amb el nou JavaScript del fitxer DRECERA_SAFARI_ZONAOK.js).

3. La drecera obrirà ZonaOK i importarà la competició. Repeteix-ho per les lligues 4789, 4786 i 4784.

4. Per a les classificacions, obre la pestanya «Classificacions» a FECAPA abans d'executar la drecera.

L'acció JavaScript ha de rebre «Entrada de la funció ràpida». Després cal l'acció «Obrir URL» amb el resultat del JavaScript. Cada pàgina requereix una lectura manual.
